# Media Mission — GitHub Pages เท่านั้น

ชุดนี้แทนชุด Python/Render เดิม ใช้ GitHub Pages อย่างเดียว ไม่ต้องเปิดเครื่องแม่ข่าย ไม่ต้องใช้ Render และไม่มีการติดตั้งแพ็กเกจ

## อัปเดตเว็บเดิม Film-Act

1. แตก ZIP นี้ก่อน อัปโหลดไฟล์ด้านในทั้งหมดสู่ราก repository `Film-Act` ไม่อัปโหลด ZIP และไม่ครอบด้วยโฟลเดอร์ชั้นนอก
2. ให้แทนที่ `index.html`, `app.js`, `style.css`, `background.js` เดิม และเพิ่ม `engine.js`, `questions.js`, `guide.html`, `.nojekyll`
3. ลบโฟลเดอร์ `.github/workflows` ของชุดเก่าที่ตั้งให้ทดสอบ Python รวมถึงไฟล์ `render.yaml`, `requirements.txt`, `gunicorn.conf.py`, `wsgi.py`, `server.py`, `content.py`, `tests/` และ `.env.example` หากมี เพราะไม่ได้ใช้ในฉบับนี้ (ไม่จำเป็นต่อการเปิดเกม แต่ช่วยไม่ให้สับสน)
4. ใน Settings → Pages เลือก Source: Deploy from a branch; Branch: main; Folder: /(root); กด Save หากตั้งไว้แล้วไม่ต้องเปลี่ยน
5. รอ GitHub Pages deploy สำเร็จ แล้วเปิด https://zoowatch.github.io/Film-Act/ กด Ctrl+F5 เพื่อโหลดไฟล์ใหม่ หากเคยเพิ่มข้อมูลในเบราว์เซอร์ เกมฉบับนี้ใช้ชื่อที่เก็บใหม่แยกจากฉบับแม่ข่าย
6. ไม่ต้องใช้รหัสห้อง BBDAA8 ไม่ต้องตั้งรหัสอาจารย์ และไม่ต้องเชื่อมบริการใดนอกจาก Forms เดิม

ถ้าต้องเลือกไฟล์ทีละไฟล์ ต้องมี 7 ไฟล์หลัก: index.html, style.css, background.js, app.js, engine.js, questions.js, guide.html (และ .nojekyll ถ้าเลือกไฟล์ซ่อนได้)
ทุกเส้นทางไฟล์ใช้ ./ เพื่อรองรับทั้งโดเมนหลักและ /Film-Act/ โดยไม่มีการเรียก /api

## วิธีเล่น

กรอกรหัสนักศึกษาและชื่อเล่น กดเริ่มเมื่ออาจารย์แจ้ง จับเวลา 40 นาทีในแต่ละเครื่อง
มีนิยาม 4 ข้อ ฝึก 6 ข้อ ประเมิน 5 ข้อ คำถามสองขั้นและการ์ดกฎหมายครบ
ประเมินข้อละ 2 คะแนน รวม 10 คะแนน ไม่ให้โบนัสความเร็ว ช่วงฝึกมี XP สำหรับตอบถูกครั้งแรก
ประเมินบันทึกครั้งแรกที่กดส่ง เฉลยเมื่อผู้เล่นนั้นส่งครบหรือหมดเวลา ข้อที่ยังไม่ส่งได้ 0 คะแนน
ความคืบหน้าบันทึกในเบราว์เซอร์เดิม เวลาเดินต่อแม้ปิดหน้า ไม่มีการซิงก์ระหว่างเครื่อง

## ส่งคะแนน

ปุ่มหน้าสุดท้ายเปิด Microsoft Forms ที่กำหนดไว้พร้อมรหัสนักศึกษา ชื่อเล่น และคะแนน นักศึกษาต้องกดส่งใน Forms อีกครั้ง เกมไม่รู้ว่า Forms ส่งสำเร็จหรือยัง
อาจารย์รวบรวมคะแนนผ่าน Responses ใน Forms แล้วส่งออก Excel เพื่อจัดอันดับภายหลัง
ไม่มีคะแนนกลางหรือตารางอันดับร่วมกัน โค้ดและคะแนนอยู่ฝั่งผู้เล่นซึ่งอาจถูกแก้ได้ กรุณาตรวจทานผลและกำหนดหลักเกณฑ์รับผลซ้ำก่อนใช้เก็บคะแนนจริง

## ตรวจสอบก่อนใช้

ทดสอบเล่นจนจบด้วยรหัสทดลอง ส่ง Forms แล้วตรวจว่าคำตอบเข้าในฟอร์มจริงก่อนแจกนักศึกษา
มีการตรวจ syntax และทดสอบตรรกะคะแนน การลองใหม่ การส่งซ้ำ การหมดเวลา และการสร้างลิงก์ Forms ในเครื่องแล้ว ยังไม่ได้เผยแพร่การเปลี่ยนแปลงไป repository ของคุณและยังไม่ได้ทำ browser interaction test
ไม่รวมข้อมูลนักศึกษาหรือรหัสอาจารย์จากเครื่องเดิมในชุดนี้
